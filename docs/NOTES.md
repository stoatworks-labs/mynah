things were missing and are now fixed:

## FOUR command languages + a real AWJ socket (2026-08-22)

`src/lang/dialects/` — **Mynah, AWJ, raw Web RCS store JSON, OSC**, one `run()`
returning one shape. Detected from the line's shape, declared with a leading
word, or pinned in the new **LanguageBar**. `parse`/`compile` are untouched and
stay the Mynah-only entry point the Stream Deck plugin uses. 193 tests.

- **`Path` now reads back**: `fromAwj`/`fromWs` are the inverse of the two
  spellings it already emitted. A truncated path THROWS rather than addressing
  the container — AWJ answers `{}` for a container, which reads as a successful
  read of nothing.
- **`src-tauri/src/awj.rs`** — a real TCP 10606 socket, one connection per
  exchange (the device allows five clients and counts them). This is what makes
  `{"op":"get",…}` answerable at all. `Link.canAwj` is the gate: false in a
  browser, true on desktop. A read on a transport that cannot do one is refused
  **by name**, never dropped.
- In a browser an AWJ message still runs — converted to the store spelling, same
  node. Only the *reply* is lost.
- `docs/LANGUAGES.md`. Settings in `src/settings.ts` (localStorage).

## Live layer control + guide (v1.3.0, 2026-08-21)

`Set` assigns **source, size, position, opacity** on a layer. `At` is accepted
before any value and a command may lead with its object (grandMA3/Titan
spellings). **`docs/GUIDE.md`** walks everything from one word up, and
`guide.test.ts` **executes every command printed in it**, so the guide cannot
drift from the grammar without a red test.

⚠️ **Live layer paths are addressed by BUFFER (`A`/`B`/`C`), NOT
`PREVIEW`/`PROGRAM`** — unlike the memory banks. Resolve with the vendor's own
rule (`bufferForMode` in `model.ts`): read `$screenAuxGroup/K/status/transition`
plus `control/{presetUp,presetDown}`; program is whichever end is up. The
compiler therefore needs **live device state** (`DeviceFacts`) and **refuses
with the reason** when it is unknown rather than guessing.

**Units: pixels AND percentages, mixable freely** — a bare number is px, `50%`
is a proportion of the canvas; mixing works within an attribute (`Size 960 25%`)
and across a command. From the device's own `POSITION_ATTRIBUTES`:
**posH/posV −2000000..2000000 (SIGNED — negatives are routine, the anchor is
the layer's CENTRE), sizeH/sizeV 0..1000000 (no negatives)**, and a layer may
exceed its canvas. A leading `-` is a **sign where a value is due and range
subtraction where a range is due** — the lexer emits the token, the parser
decides.

Other device facts confirmed on the sim:
- source is an **enum** — `LIVE_1`..64, `STILL_1`..48, `SCREEN_1`..24,
  `NATIVE_1`..8, `SHARE_1`..32, `COLOR`, `NONE` — not a number
- position/size are **pixels**, anchor `MIDDLE_CENTER`, so posH is the layer's
  **centre**
- **opacity is 0–256**, not 0–100
- a percentage needs the canvas (`$screen/K/status/size/{sizeH,sizeV}`)

**A keyword may appear only ONCE in the table** — Source/Position/Size/Opacity
are declared as attributes and read as record-mask categories inside `If`;
duplicating them cost every one of them its abbreviation.

## Desktop app (v1.1.0, 2026-08-21) — and WHY it exists

Tauri 2, macOS/Windows/Linux, **~4.6 MB .app**. `npm run desktop` /
`desktop:build`; `.github/workflows/desktop.yml` builds all four on a `v*` tag
(Intel mac CROSS-COMPILED on Apple silicon — macos-13 runners are capacity-dead).

**The device I/O is in RUST, not the webview, and it had to be.** Tauri
registers its custom scheme as a *trustworthy origin*, so the webview is a
**secure context** — and a secure context may not open a plain `ws://` any more
than an https page may. Putting the socket in `src-tauri/src/link.rs` removes
the browser sandbox from the path entirely. Same reason
[livepremier vpu visualizer](https://github.com/stoatworks-labs/aquilon-vpu-map/blob/main/docs/NOTES.md) (`aquilon-vpu-map`) does its AWJ in Rust.

`src/link/transport.ts` is the shared interface; `isDesktop()` checks
`__TAURI_INTERNALS__` and picks `DesktopLink` (IPC) or `WebRcsLink` (browser
WebSocket). Nothing above `Link` differs. Tauri CSP `connect-src` is **ipc only**
— the webview never opens a socket.

Verified: `cargo check` clean, **6 Rust unit tests**, bundle builds and launches,
and `cargo test --test live -- --ignored` connects to the running simulator and
confirms the frame is echoed. **Unsigned on macOS** ([apple codesigning](https://github.com/stoatworks-labs/fleet-notes/blob/main/notes/project_apple_codesigning.md)).

## ⚠️ A https copy can NEVER drive a switcher, and NO PROXY FIXES IT

Asked directly whether the hosted tool could forward https down to http. It
cannot, for two independent reasons:
1. A **Cloudflare Worker runs at the edge and cannot reach a private address** —
   a switcher on 192.168.x.x is unroutable from Cloudflare's network.
2. Tunnelling the device out (cloudflared/ngrok) would work technically but
   **exposes an unauthenticated control interface to the internet** — anyone
   reaching it drives the show. Do not build this.

The **desktop app is the answer to that question.**

The device serves plain http/ws on **80 with 443 CLOSED**, and browsers block an
insecure WebSocket from a secure page as mixed content. So the hosted
Cloudflare copy is a **syntax reference and offline compiler only**. Live
control needs an http origin — localhost or a self-hosted copy on the show
network. The app detects `location.protocol === 'https:'` and reports a
`blocked` link state with an explanation rather than an unexplained
"Connection failed". `connect-src` in `public/_headers` must allow
`ws: wss: http:` or even the http copy breaks in production only.

"Mynah" is a working name I picked (a bird that repeats what it is told);
Allan renames things mid-build, so treat it as provisional.

## What it is

A command line for Analog Way LivePremier: type `Recall Screen 1 Memory 5`,
press Enter. **Scope confirmed by the user**: grandMA3's *grammar rules* with
the switcher's own *nouns* — never "fixture" or "cue". Reference material Allan
supplied: grandMA3 `csk_syntax_rules`, ChamSys MagicQ programmer (403s to
WebFetch), Avolites Titan reference.

First pass = **memories only**: Recall, Store, Take, Delete, Label, Select,
Clear over Screen / Aux / Layer / Master / Multiviewer, with `Thru` / `+` / `-`
ranges and an `If` record mask. Explicitly expected to grow over the ~2,040
recovered object-model modules; the grammar is built so growth is new *object
keywords*, not new rules.

## The decisions Allan made

- **Transport: Web RCS WebSocket, direct.** AWJ is unreachable from a page, so
  the Web RCS socket is the only way in. No bridge, no install.
  **Be precise about why** (2026-08-21): a page *can* open a TCP connection to
  10606 — that port is not on the Fetch spec's blocked-port list — it just can
  only ever speak HTTP or the WebSocket handshake over it, and AWJ is a raw
  `0x04`-framed JSON stream ([awj protocol](https://github.com/stoatworks-labs/fleet-notes/blob/main/notes/reference_awj_protocol.md)). The device drops the
  handshake. So the *outcome* is unreachable, but the mechanism is "no raw byte
  stream", not "no connection". The distinction matters: a **timing probe** of
  10606 (WebSocket open, measure `onerror` latency) would work fine from an http
  origin, so device discovery is possible even though control never will be.
  Same reason the defuse.ca in-browser-port-scan trick is only ever an existence
  oracle.
- **Grammar: grandMA3 rules, AV nouns.**
- **Deliverable: spec + working tool**, not a spec to approve first.
- **All three input devices in v1** — keyboard, X-Keys, Stream Deck.

## Shape

`src/lang/` is DOM-free, network-free and transport-agnostic; the web tool and
the Stream Deck plugin are two front ends onto it. **Parser resolves, compiler
decides** — the parser applies no defaults, all policy is in `compile.ts`.

**Keyword short forms are COMPUTED, never written down.** Ambiguity resolves
across the whole vocabulary, so adding a word changes its neighbours: `Master`
is `Mast` and **`Mask` has no abbreviation at all** because `Mas` is shared. A
test asserts every keyword still resolves from its own computed short form.
I hand-wrote the short-form table first and half of it was wrong (`Tk` is not
even a prefix of `Take`) — that is why it is derived.

**Defaults are deliberately asymmetric**: an unqualified `Recall` goes to
**Preview**, an unqualified `Store` takes from **Program**. Reaching air always
costs an explicit word. Do not make this configurable.

Devices: X-Keys via **WebHID direct from the page** (a plain HID device nothing
claims). **Stream Deck cannot be** — Elgato's software holds it, so it is a
plugin in `streamdeck/` that is a *second independent client* of the switcher,
importing the same lang core and opening its own socket. A Stream Deck key has
**no sticky scope** by design.

## VERIFIED ON REAL HARDWARE 2026-08-21

Allan offered the live **Aquilon C** (`NLC_C`, fw 6.2.73) and explicitly
authorised a **full test including Take**, confirming it was a bench box with
nothing downstream. That supersedes the old read-only rule *for that session
only* — *[livepremier vpu visualizer](https://github.com/stoatworks-labs/aquilon-vpu-map/blob/main/docs/NOTES.md) (`aquilon-vpu-map`)'s "be delicate" default still
stands, ask again next time.*

- **21/21 memory-bank paths resolved** on the real box, zero failures.
- Every verb executed from the command line: store, recall, label, delete, a
  layer memory on S3, a program recall, a **Take**, and the six-op masked
  master store with its filters read back exactly as compiled.
- Test memories (screen 901, master 12, layer 40) **deleted afterwards; box
  left clean** and the master filters back to wide open.
- The box has **no memories stored at all** and S1–S4 configured; S1 canvas is
  3840x2160.

**Two bugs only hardware found**, both fixed:
1. A **`Label` reported "unconfirmed" while landing perfectly.** The echo
   matcher only accepted a value of `true`, so labels (strings) and every
   master-store filter (arrays) could never be acknowledged. Match the value
   actually sent.
2. **Preview is not a fixed buffer per screen** — one recall pass landed on
   buffer **A for S1** and **B for S2–S4** simultaneously. Nothing may
   hard-code it. See [livepremier memory banks](https://github.com/stoatworks-labs/fleet-notes/blob/main/notes/reference_livepremier_memory_banks.md).

Mid-test the device went unreachable for ~1 min on both 80 and 10606 while ARP
still held its MAC and the link stayed up; it returned by itself with the
deletes landed and the save filters reset to default — consistent with a
control-service restart, **cause never proven**. Do not panic-diagnose the
network: `192.168.2.1` has no host on it, so "gateway unreachable" means
nothing here.

Stream Deck plugin smoke-tested against a fake Elgato socket. **NOT tested:**
any real X-Keys panel, any real Stream Deck. 45 unit tests, clean `tsc -b`.
